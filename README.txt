Dr. Shian L. Peterson, MD - Website
===================================

This is a responsive, static website providing information about Dr. Peterson,
joint replacement preparation and recovery, nutrition, and publications.

Pages
-----
- index.html: Home page, biography, education, professional associations, and
    AAHKS surgery resources.
- preop.html: Joint replacement preparation and recovery information.
- nutrition.html: Nutrition guidance for surgery preparation and recovery.
- publications.html: Featured research and publication links.
- resources.html: Additional patient education and support information. This
    page is not currently linked from the main navigation.

Run Locally
-----------
No build step or package installation is required. Open index.html directly
in a web browser. The other HTML files can also be opened directly. For local
development, serve this folder with any static file server and open its URL.

Project Files
-------------
- *.html: Page content and navigation.
- css/style.css: Shared layout, responsive behavior, and visual styles.
- script.js: Mobile navigation behavior and rotating home-page messages.
- images/: Page photography, logos, illustrations, and the site favicon.
- README.txt: Project notes.

Making Changes
--------------
- Edit the relevant HTML file to change page content or links.
- Edit css/style.css for shared styling and responsive layout.
- Edit script.js for navigation or interactive behavior.
- Keep image paths relative to the HTML file, for example images/headshot.png.

The site imports web fonts from Google Fonts, so those fonts require an internet
connection; the browser uses fallback fonts if they are unavailable.
